# English reference voices

English (and other personas that list `en` in `language_ids`) live here.

- Reference clips: `*.wav` (e.g. `Dave.wav`)
- Synthetic previews: `*-preview.mp3` (see `preview_filename` in `voices.json`)

Paths in **`voices.json`** use the `en/` prefix, e.g. `"filename": "en/Dave.wav"`.
